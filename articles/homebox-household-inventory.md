电钻明明买过，找的时候却不知道在哪个箱子里；洗衣机需要维修，发票和保修资料又散在邮件、相册和抽屉里。
这些麻烦都有一个共同点：物品还在，关于它的信息却很难一起找到。

Homebox 是面向家庭用户的开源物品管理工具，可以通过浏览器记录家里有什么、放在哪里，以及购买和维护情况。
这里介绍的是 `sysadminsmedia/homebox` 仓库维护的项目，官方提供网页演示和自托管安装文档[1]。

## 给物品一个能找得到的位置

Homebox 支持分类、位置、标签和自定义字段，也提供搜索功能。
位置可以逐层嵌套，例如“书房—工具柜—第二层”，标签则适合标记“维修工具”“露营装备”等跨房间的用途[1][2]。

这种分法适合东西分散在多个柜子、储物间或箱子里的家庭。
收纳位置负责回答“去哪里拿”，标签负责回答“同类东西有哪些”；搬动东西时，只需要把对应记录的位置改成新的去处。

![Homebox 官方文档中的位置树界面](https://aronshare.com/assets/post-images/homebox-household-inventory-locations.png)

官方文档示例展示了车库、柜子和层板之间的层级关系[2]。

每件物品可以记录名称、说明、数量和位置，并附上照片及其他文件。
进入编辑页的高级模式，还能补充购买、保修、出售情况和自定义字段；官方 README 也列出了维护计划跟踪能力[1][3]。
照片适合辨认外观相近的配件，说明书和购买凭证则可以直接附在对应物品上，减少临时翻找不同文件夹的次数。
