# Navidrome 让你在手机和浏览器里听自己收藏的音乐

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_navidrome-music-server.webp)](https://aronshare.com/posts/navidrome-music-server/)

买了数字专辑，或者从 CD 抓轨存下来的音乐，躺在硬盘里只能坐在电脑前听。
Navidrome 把这些文件变成一个手机、平板和浏览器都能访问的音乐库，曲库还是自己那份。

它是开源的网页音乐服务器。
装好之后指向音乐目录，扫描完就能按专辑、艺人和歌曲浏览，官方给它的定位是给自己的收藏做一个私人 Spotify。

库大了也能扛。
官方说明里写的是面向超大的音乐收藏设计，资源占用低，macOS、Linux、Windows 都有现成二进制，树莓派的包也提供，Docker 镜像同样有。

格式兼容是它的重点之一。
几乎各种音频格式都能直接流式播放，遇到客户端不支持的格式，可以按用户或者播放设备开启转码，Opus 编码也在支持范围里。

![Navidrome 桌面端界面，左侧是专辑分类，右侧是专辑网格和播放队列](https://aronshare.com/assets/post-images/navidrome-music-server/detail-1.webp)

*官方仓库截图，专辑视图旁边可以直接拉开播放队列。*

多用户各有各的数据。
播放次数、播放列表、收藏都分开记，家里人共用一台服务器时不会互相覆盖。
音乐目录有变化它会自动重新扫描，新拷进去的专辑不用手动重建索引。

![Navidrome 手机端专辑页，曲目列表支持收藏、加入播放列表和下载](https://aronshare.com/assets/post-images/navidrome-music-server/detail-2.webp)

*手机浏览器里的专辑页，单曲右侧的三点菜单是常用操作入口。*

歌词支持也做了。
除了文件内嵌的标签，还能读 .lrc、.srt、.ttml 这类外部歌词文件，本地整理过歌词的库可以直接用。

客户端不用另找生态。
它兼容 Subsonic、Madsonic、Airsonic 这一系的客户端，手机上装个现成的播放器，填上服务器地址和账号就能听，网页界面本身也能换主题。

安装走官方文档里的 Docker 或者二进制包，指向音乐目录、配好端口就行。
曲库命名乱的话，先在电脑上把专辑目录和标签整理一遍，扫出来的封面和艺人才干净。

维护成本不高，但两件事值得做。
一是定期备份数据库目录，播放列表和收藏都在里面；二是别把音乐目录设成只读之外的奇怪权限，扫描进程读不到文件就会一直报错。
