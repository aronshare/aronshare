## 笔记本、标签和搜索各有用途

Joplin 用笔记本组织内容，笔记可以添加标签，也可以通过全文搜索查找。
正文支持图片、视频、PDF 和音频等资料，因此一份项目记录能够同时放下会议结论、参考图片和相关附件。
这些能力见于官方的产品介绍与入门说明。

例如，准备一次网站改版时，可以建立“网站改版”笔记本，把用户反馈、页面参考和会议记录分别保存成笔记。
需要交叉查找的内容加上“导航”“移动端”等标签，后续围绕同一问题查资料时，就有明确的检索线索。
这是整理方式的建议，实际目录可以按自己的项目调整。

![Joplin 官方展示的桌面和手机笔记界面](https://aronshare.com/assets/post-images/joplin-offline-notes-official-ui.png)

*图片来自 Joplin 官网，展示笔记本、标签、待办、表格与附件在桌面和手机端的呈现。*

编辑时可以选择 Markdown，也可以使用所见即所得的富文本编辑器。
两者背后使用的笔记格式仍是 Markdown，因此复杂排版需要考虑兼容性。
官方说明特别提醒，部分 Markdown 插件的特殊格式在富文本编辑器中可能丢失，表格也受 Markdown 格式限制。
经常依赖插件语法的人，适合保持在 Markdown 编辑器中处理这类笔记。
