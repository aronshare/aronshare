# Jellyfin 让你把硬盘里的电影变成家里随时能看的视频库

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_jellyfin-media-server.webp)](https://aronshare.com/posts/jellyfin-media-server/)

硬盘里存了几百 G 的电影和剧集，想在客厅电视、卧室平板和手机上接着看，每次都要拷来拷去。
把文件放进一个目录交给 Jellyfin 管，打开网页就能挑片播放。

Jellyfin 是开源的媒体服务器，把本地视频整理成带海报墙、简介和演员信息的资料库，用浏览器或者客户端播放。
库的类型覆盖电影、剧集、音乐和照片，一台服务器可以给家里人开多个账号，各自保存观看进度和收藏。

安装方式按平台分得比较细。
官方文档列了 Windows、macOS、Debian 与 Ubuntu、其他 Linux 发行版、Docker 与 Kubernetes、Synology 和 TrueNAS 社区版的安装入口。
家里有闲置小主机或者群晖，照文档对应那一页走就行。
官方文档也写明了 FreeBSD 及其衍生系统（比如 TrueNAS CORE）不作为支持平台，选机器之前先确认自己的系统在名单里。
TrueNAS 社区版基于 Linux，走它自己的应用仓库安装，这个应用由社区维护，出问题先找 TrueNAS 的支持渠道。

播放时最常卡住的地方是编码。
电视盒子认不出某些视频格式，服务器可以实时转码成客户端能播的流，代价是吃 CPU。
机器带核显或者独显就能打开硬件转码，把活交给显卡，性能一般的机器也能同时供几个人看。

*官方演示服务器的首页，电影库按继续观看和最新添加排开。*

多用户这件事在家庭场景很实用。
每个人登录自己的账号，孩子的账号可以单独限制能看的分级，不用每次手动挑片。
观看进度也是分开记的，客厅看了一半，回房间打开手机能接着播。

![Jellyfin 电影库列表，按字母索引排列，上方有筛选和排序入口](https://aronshare.com/assets/post-images/jellyfin-media-server/detail-2.webp)

*电影库页面，海报下方是片名和年份，右侧字母索引用来快速翻库。*

准备工作有三样。
一台常年开机的机器，一块放片源的硬盘，以及按官方规则整理好的目录结构和文件名。
命名越规范，刮削出来的海报、简介和集数越准，后期手动修补的活越少。
片源版权由自己负责，服务器只解决整理和播放。

想先看界面，官方有在线演示站，不装也能点开。
真要长期用，建议先用 Docker 起一个容器放几部片子试一周，确认转码和局域网访问都顺，再决定要不要迁到独立机器上。
局域网里用最省事，出门在外想接着看，得自己处理端口转发或者反向代理，顺手把 HTTPS 配上。
