# IT-Tools 把开发和运维常用的小工具收进一个网页

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_it-tools-devtoolbox.webp)](https://aronshare.com/posts/it-tools-devtoolbox/)

手头这些活都很小。
把一个字符串算成 MD5，比对一下文件有没有被改过。
把接口返回的时间戳换成能看懂的年月日。
把一段 JWT 拆开，看看里面到底写了什么。
把一条 docker run 命令改成 compose 文件。
为了这几秒钟的事去装一个客户端，或者注册一个来路不明的网站，成本都不对等。
更麻烦的是数据，公司内部的配置、密钥、证件号，粘进别人的网页里，谁也不知道它背后有没有存一份。
这类小工具平时不显眼，真卡住的时候又绕不开。
收藏夹里攒了一堆各家的在线工具，谁家域名换了、广告变多了，用起来心里没底。
IT-Tools 就是冲这个场景来的，一个网页里装了一堆开发和运维常用的小工具，打开就填，不用注册。

## 一页里装了什么

官方把工具分成十类，左边栏点下去就能找到。
加密这一类放的是 token 生成、文本哈希、bcrypt、UUID 和 ULID 生成、对称加密解密、BIP39 助记词、HMAC、RSA 密钥对、密码强度分析，还有 PDF 签名检查。
哈希那一项支持 MD5、SHA1、SHA256、SHA224、SHA512、SHA384、SHA3 和 RIPEMD160，一次算完一起列出来。
转换这一类最长，时间戳和日期互转、进制转换、Base64 字符串和文件、颜色格式、大小写、NATO 字母表、文本转二进制、YAML 与 JSON 与 TOML 互相转、XML 转 JSON、Markdown 转 HTML 都在里面。
Web 这一类是给写页面的人准备的，URL 编解码、HTML 实体转义、URL 解析、JWT 解析、OTP 验证码、MIME 类型、meta 标签生成、user-agent 解析、HTTP 状态码速查、JSON 对比。
开发这一类最贴日常，git 速查表、crontab 生成、JSON 格式化和压缩、JSON 转 CSV、SQL 格式化、chmod 计算器、XML 和 YAML 格式化、正则测试器、正则速查表。
网络这一类是 IPv4 子网计算、IPv4 地址转换、地址段展开、MAC 地址查询和生成、IPv6 ULA 生成。
剩下四类分别是数学、测量、文本和数据，二维码和 WiFi 二维码归在图片与视频下面。
左栏的分类是折叠的，展开一类才看到下面的工具，屏幕小的时候不会一次糊满。
日常卡住的那三十秒，多半能在这一页里找到对应格子。
具体到单个工具，给的东西比想象中多。
时间那一项填一个时间戳进去，JS 的日期字符串、ISO 8601、ISO 9075、RFC 3339、RFC 7231、Unix 时间戳、毫秒时间戳、UTC 写法、Mongo 的 ObjectID、Excel 的日期序列，十种写法一次全给出来，右边配一个复制按钮。
颜色那一项把 hex、rgb、hsl 和 CSS 颜色名互相转，改主题色的时候不用来回开设计软件。
JSON 那一项分成几件事，格式化、压缩、转 CSV、两份 JSON 对比各占一个工具页，比在一个页面里堆一堆按钮清爽。
每个工具都有自己的网址，把链接直接发给同事，对方打开落到的就是同一个工具。
