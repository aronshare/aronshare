# PhotoPrism 帮你按人物和拍摄信息找回散落的照片

照片按年份存进硬盘后，找图仍然可能很费劲。
想找某次旅行的合照，只记得同行的人和大致地点，文件名和文件夹往往帮不上忙。
[PhotoPrism](https://github.com/photoprism/photoprism)可以为照片和视频建立可搜索的图库，让你用人物、内容标签和拍摄信息缩小查找范围。

它适合已经积累大量照片、希望自己管理存储位置的人。
服务运行在自己的电脑或服务器上，日常通过浏览器使用，手机和平板也能访问。

## 找照片可以从画面内容入手

PhotoPrism 的官方功能介绍包括内容自动标注、人脸识别，以及多种可以组合使用的搜索条件。
除了标签和地点，还能按分辨率、颜色等属性筛选，遇到混在一起的相机照片、手机照片和视频时，可以用这些条件逐渐缩小范围。

照片本身的拍摄信息也会参与整理。
它可以提取和合并 Exif、XMP 等来源的元数据，图库卡片能够显示拍摄日期、相机参数、文件格式和地点。
对于保存 RAW 原片的用户，这些信息尤其有用，查图时能同时了解照片的拍摄情况和文件情况。

![PhotoPrism 图库卡片显示照片、拍摄参数、文件格式与地点](https://aronshare.com/assets/post-images/photoprism-private-photo-library/detail-1.webp)

*图片来自 PhotoPrism 官方仓库，展示搜索入口、图库卡片与照片元数据。*

自动标注适合帮助缩小范围，自己熟悉的人物姓名和相册主题则适合手动补充。
例如整理一趟旅行时，可以用地点找到相关图片，把需要保留的照片归入同一个相册，之后按相册直接打开。
