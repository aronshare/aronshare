# Beszel 帮你在一个页面看清服务器和容器的运行状态

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_beszel-server-monitor.webp)](https://aronshare.com/posts/beszel-server-monitor/)

服务器上的服务越来越多，排查卡顿也会变麻烦：究竟是哪台机器内存紧张，还是某个容器突然占满了 CPU？
逐台登录查看终端，容易漏掉已经过去的异常时段。
Beszel 提供服务器资源监控面板，把多台主机的状态和历史曲线放到浏览器里，并支持按指标设置告警。

它适合管理个人 VPS、家庭实验室和运行多个容器的小型环境。
选用它之前，值得弄清楚监控数据从哪里来，以及管理端与被监控机器如何连接。

## 从主机列表定位到具体容器

[官方 README](https://github.com/henrygd/beszel)列出的基础指标包括 CPU、内存、磁盘占用、磁盘读写、网络流量和系统负载。
主机列表适合快速比较不同机器；进入单台主机页面，可以查看指标随时间的变化，定位异常发生的时段。

容器层面支持 Docker 和 Podman，能够查看运行状态，以及 CPU、内存和网络使用情况。
例如，发现某台机器负载升高后，可以对照同一时段的容器曲线，缩小需要检查日志的范围。
这是使用监控数据的排查思路，具体原因仍需结合应用日志和业务请求判断。

![Beszel 官方历史示例截图展示主机列表和单台主机的资源曲线](https://aronshare.com/assets/post-images/beszel-server-monitor-ui.png)

图为官方 README 提供的界面示例，左侧是主机列表，右侧是资源与容器曲线。
截图中的数值和 Agent 版本属于官方演示环境。

项目还列出了温度、风扇转速、GPU、磁盘 S.M.A.R.T. 和 ZFS 等指标。
这些数据取决于操作系统、硬件传感器及运行权限，例如风扇转速读取使用 Linux 的硬件监控接口。
选择部署方式时，应围绕自己实际需要的指标检查支持条件，避免把全部功能列表当成每台机器都会出现的数据。
