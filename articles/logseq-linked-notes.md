# Logseq 帮你把读书笔记和项目记录串成知识库

[![封面图片](https://aronshare.com/covers/cover_logseq-linked-notes.webp)](https://aronshare.com/posts/logseq-linked-notes/)

同一个项目的信息，往往散在每天的会议记录、读书摘录和待办清单里。
回头写方案时，能找到某一篇笔记，还得继续翻找相关的讨论和决定。
Logseq 用双向链接把这些记录连接起来：内容可以留在写下它的那一天，通过项目名、人物或主题汇集到一起。

它是一款开源知识管理工具，采用带层级的大纲式编辑方式，也提供 PDF 标注、任务管理、插件和主题。
每个带圆点的条目都是一个“块”，一条想法、一段摘录或一个任务都能独立引用。
这套结构适合持续积累的资料，例如课程笔记、研究素材和项目日志。

## 日记负责记录，链接负责把资料找回来

Logseq 的 Journals 是按日期组织的日记入口。
你可以把当天会议、读到的内容和临时想法记在同一页，用缩进区分主题及其补充信息。
条目多了就折叠暂时不用的分支，点击圆点还能聚焦某一组内容。

下面的用法以 Logseq 的文件图谱为例。
在日记里写下 `与 [[网站改版]] 有关的首页建议`，`[[网站改版]]` 就成为页面链接。
打开这个页面，底部的 Linked References 会列出从其他位置链接过来的记录。
以后在另一篇日记提到同一个项目，也能从项目页找到那段讨论，无须把原记录搬走。
