# Umi-OCR 帮你把截图和扫描件里的文字直接抠出来

[![封面图片](https://aronshare.com/covers/cover_umi-ocr-offline-text-recognition.webp)](https://aronshare.com/posts/umi-ocr-offline-text-recognition/)

视频课截图里写着报错信息，一份扫描合同只有图片没有文字层，PPT 导出的长图里全是不能复制的句子。
这些材料的共同点是文字已经在图片里，键盘却敲不出来。
Umi-OCR 处理的就是这类活，它把图片里的字识别成可以直接编辑、搜索和复制的文本。

这是一款免费开源的离线软件，代码公开在 GitHub 上，识别过程在自己的电脑里完成。
下载包解压后双击 Umi-OCR.exe 就能启动，不用安装，也不用把文件传到别人的服务器。
官方说明支持 Windows 7 x64 和 Linux x64，macOS 还在远期计划里。

## 截图之后马上出文字

打开「截图OCR」标签页，用快捷键框选屏幕上的区域，松手就开始识别。
结果出现在右侧记录栏，可以逐条修改，也能划选多条一起复制。
左侧预览保留原图，文字块以高亮方式叠在图上，哪一段对应哪里一眼能看出来。

在别处复制一张图片，直接粘贴进 Umi-OCR 也能识别，省掉把图片存成文件的步骤。
识别结果的换行和顺序由「文本后处理」里的排版解析方案决定。
多栏文档用「多栏-按自然段换行」，代码截图用「单栏-保留缩进」，行首缩进和行内空格会跟着留下。
方案不合适就换一个，同一张图重新识别一次即可。
