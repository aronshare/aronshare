# Gitea 帮你把代码仓库放到自己服务器上

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_gitea-selfhosted-git.webp)](https://aronshare.com/posts/gitea-selfhosted-git/)

公司里几个人的代码放在第三方平台上，账号是别人的，仓库也是别人的。
哪天平台改规则、涨价或者网络不通，日常开发就卡在那里。
更麻烦的是交接，人一离职，仓库归属和权限就得重新扯一遍。
Gitea 做的事情很直接，它把整套 Git 托管服务搬到你自己的一台服务器上，用浏览器就能访问。

## 什么情况下该用它

代码属于公司资产，托管账号却挂在个人名义下，时间久了必然出问题。
内网开发的项目，源码不方便出公网，外部平台从网络这一层就连不上。
私有仓库越开越多，按人按月付费的账单开始变得难看。
有些行业对代码存放位置有硬要求，数据必须留在自己机房，这类场景只能自建。
老项目散落在不同平台，Gitea 支持从其他 Git 服务迁移仓库，也支持把提交定时镜像到外部仓库。
这几种情况都指向同一个做法，找台机器把服务自己跑起来。
Gitea 是自托管的 Git 托管服务，装完之后团队访问的是自己的域名，克隆地址也是自己的。
它开源，许可证是 MIT，官网写明免费版不限用户数和仓库数。
开源还留了一条后路，项目哪天没人维护，代码和数据库都在自己手上，换方案或者自己接着改都行。
公司另外提供付费的 Gitea Enterprise，加了单点登录、审计日志和 SLA 支持，普通团队用开源版就够。
