# RomM 把几千个 ROM 整理成游戏库，浏览器里点开就能玩

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_romm-game-library.webp)](https://aronshare.com/posts/romm-game-library/)

手里攒了十几年的 ROM，时间一长通常变成一堆按字母命名的文件夹。

名字是缩写，封面没有，哪一版是哪一版分不清，孩子想玩的时候你翻半小时也说不清哪个是《超级马里奥世界》。

RomM 是专门收拾这堆东西的。它是自托管的 ROM 游戏库管理器兼播放器，AGPLv3 许可，负责扫描目录、补元数据、整理成网格，再让你在浏览器里直接开玩。

打开是这样的界面：左边按平台列出主机名和各自的游戏数，中间是整屏的封面网格，顶上一个搜索框。

![](https://aronshare.com/assets/post-images/romm-game-library/detail-1.webp)

封面不用自己找，它会去 IGDB、Screenscraper、LaunchBox、MobyGames 等十多个元数据源抓，封面图还能从 SteamGridDB 拉。

覆盖 400 多个平台，多碟游戏、DLC、改版、模组、说明书都能挂在同一个条目下，不乱。

真正让它在同类里突出的是浏览器直接跑游戏这一层。

它靠 EmulatorJS 和 RuffleRS 在网页里模拟运行，用户端不用装任何模拟器，打开链接点开始玩就行，手机浏览器也行。

![](https://aronshare.com/assets/post-images/romm-game-library/detail-2.webp)

这张是官方演示动图的第一帧，首页上能看到库统计 167 个游戏、13 个平台，最近添加 16 个，下面按平台列出每个平台上收了多少个。

第二张图取自动图首帧这件事得说清楚：官方给这个界面的是动图，我截了第一帧当静态图用，内容没有改动。

它还有个内置的 ROM patcher，能直接给 ROM 打补丁，汉化补丁和 romhack 就地在网页里处理，不用另装工具。

存档和即时存档支持多设备同步，带冲突处理，你在电脑上打到一半，手机接着打。

权限这块按用户分，细到能控制谁看得到哪个平台，也支持 OIDC 单点登录，一家人或一个小群共用一套库不至于互相干扰。

官方还给了三个客户端：Playnite 插件、Android 掌机端 Argosy、CFW 端 Grout。

代价说清楚。

自建要走 Docker，配好目录映射，ROM 文件名规则要按它的要求来，乱命名会导致识别不出来。

元数据抓取依赖外部数据源的接口，某些平台冷门游戏抓不到，到头来还是要手工填。

软件本身免费，没有付费功能，官方也没有卖 Pro 档。不想自己搭的话它给了两家托管部署入口，起价分别是每月 2.30 美元和 6.49 美元，这两家会把一部分收入返给项目。

这里要说一句边界：ROM 的合法性取决于你所在地区的法律和你手上的原始卡带，这套工具只是管理本地文件。

谁适合用：手里有大量老游戏、想要一个能按封面翻的库的；给家里孩子搭一台复古游戏机的；有 NAS 并且愿意花一个周末整理目录的。

谁别碰：只是想玩两三个游戏、不愿意折腾目录结构的，装个模拟器前端更省事。

官网 romm.app，源码在 github.com/rommapp/romm，快速开始文档里给了 Docker Compose 的完整配置。
