# Zed 让你在编辑器里带着文件上下文和 AI 一起改代码

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_zed-ai-code-editor.webp)](https://aronshare.com/posts/zed-ai-code-editor/)

改一个跨好几个文件的函数，来回复制代码贴到网页聊天框里问，贴完还要手动搬回去。
Zed 把 AI 面板放进编辑器，当前文件可以直接加进上下文，回答和改动都在同一个窗口里完成。

Zed 是用 Rust 写的代码编辑器，团队做过 Atom 和 Tree-sitter。
它主打响应速度和多人协作，macOS、Linux、Windows 都有安装包，也能用系统的包管理器装。

AI 面板是它的一个重点。
新建一个对话线程，把文件或者选中的代码加进上下文，提要求之后它给出改动建议，历史会话按时间留在侧栏，回头能翻。

![Zed 编辑器与 AI 面板并排，右侧是新建对话和历史交互列表](https://aronshare.com/assets/post-images/zed-ai-code-editor/detail-1.webp)

*官方截图里的 AI 面板，底部可以看到当前文件已经加进上下文。*

版本控制做进了主界面。
左侧列出改动的文件，右侧是逐块的差异对比，每个代码块旁边有暂存和还原按钮，左下角填提交信息，改完直接提交。

![Zed 的 Git 面板，左侧是变更文件列表，右侧是按块对比的差异视图](https://aronshare.com/assets/post-images/zed-ai-code-editor/detail-2.webp)

*未提交改动的视图，按文件分块展示，可以只暂存其中一块。*

许可证是 GPL-3.0。
源码在 GitHub 上公开，标注过的部分组件用 Apache-2.0，想自己编译改动都能做。

使用成本分两块。
编辑器本身免费下载，AI 功能要登录账号，能用的模型和额度按官方方案走，重度使用前先看清计费方式。

上手建议很简单。
用熟悉的项目跑一遍多文件搜索、Git 面板和 AI 面板，确认快捷键习惯能接受，再决定要不要换掉现在用的编辑器。

它还支持多人协作。
同一份代码开一个共享工作区，其他人可以进来一起看、一起改，远程结对时不用再开屏幕共享。
语言支持走 LSP，常见语言的补全和跳转靠装对应语言服务，编辑器本身不预装全部。
