# NocoDB 让你把现成数据库变成能直接填写的表格

> 💡 **资源说明**：本文档为精选摘要镜像，完整工具介绍、官方入口与使用条件请前往 AronShare 官网浏览。

[![封面图片](https://aronshare.com/covers/cover_nocodb-database-ui.webp)](https://aronshare.com/posts/nocodb-database-ui/)

业务数据已经躺在数据库里，同事要看列表、改状态、导一份表，还是得找人写页面或者单独开账号。
NocoDB 接上这个库，直接生成一套能点开就用的表格界面。

它的定位是把数据库变成在线表格。
连上现成的库之后，表结构和记录直接用网格展示，不用另外再建一套数据。

视图不止一种。
官方列出的类型有网格、画廊、表单、看板和日历，同一张表可以按不同场景各建一个视图，字段显示和筛选条件分别保存。

![NocoDB 表格视图，左侧是库和表的结构，中间是按阶段分组的记录列表](https://aronshare.com/assets/post-images/nocodb-database-ui/detail-1.webp)

*官方演示库里的销售表，按阶段分组显示，金额和负责人都是独立字段。*

字段类型覆盖得比较全。
编号、链接、查找、汇总、附件、货币、公式、用户这些都能选，表单视图收上来的数据会直接写进对应字段。

![NocoDB 的记录列表视图，工具栏里有字段、筛选、分组和排序](https://aronshare.com/assets/post-images/nocodb-database-ui/detail-2.webp)

*同一个库的另一个视图，工具栏可以切换字段显示和筛选条件。*

分享和权限是它面向团队的卖点。
可以把一个库或者视图设成公开链接，也能加密码保护；协作视图和锁定视图分开管理，填表的人不会动到表结构。

安装最省事的方式是 Docker。
官方 README 给了 SQLite 和 PostgreSQL 两种起法，一条 docker run 带个数据卷就能跑起来，默认 8080 端口。

许可证得单独说明。
它现在用的是 Sustainable Use License，源码公开，个人使用和公司内部业务使用免费，对外提供收费的托管或服务需要先取得授权。
商用之前把条款读完，再判断这套方案能不能放进自己的业务里。

自己维护要注意版本。
容器升级前把数据卷备份出来，库结构和视图配置都在里面，换镜像出问题时能退回上一个版本。
