维护网站时，业务数据可能放在 MySQL，另一个项目使用 PostgreSQL，本地小工具又留下了 SQLite 文件。
如果每种数据库都准备一套客户端，查表、写查询和导出数据就要反复切换操作习惯。
DBeaver Community 可以在一个桌面程序里管理这些连接，让日常工作围绕数据库和查询展开。

它适合需要经常查看表结构、核对数据、执行 SQL 的开发者，也适合有数据库访问权限的数据分析人员。
Community 版免费开源，日常关系型数据库操作可以从这个版本开始。

## 从表结构到查询结果都能在窗口里查看

DBeaver 的左侧导航树用来展开连接、数据库、表和字段，中间区域可以打开 SQL 编辑器，查询结果则显示在表格中。
查看一张陌生的业务表时，你可以对照字段和约束编写查询，把需要的记录筛选出来，也可以借助 ER 图理解表之间的关系。
官方功能介绍还列出了数据编辑、导入导出、执行计划和 SSH 隧道等能力[1]。

![DBeaver 官方 SQL 编辑器截图，左侧是数据库对象，右侧显示查询和结果表](https://aronshare.com/assets/post-images/dbeaver-database-client.png)

*图片来自 DBeaver 官方产品页，展示 SQL 编辑器与示例数据，属于官方演示界面。*

例如，开发者排查某个订单状态时，可以根据业务表的实际字段编写查询，检查结果中是否存在重复记录、空值或状态异常。
需要把结果交给同事时，可以导出当前查询的数据，而不用把整张表的内容都交出去。
这种使用方式的价值在于把结构查看、查询和结果整理连在一起；查询逻辑和数据权限仍需要由使用者确认。
